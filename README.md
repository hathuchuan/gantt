# MD Editor

Trình soạn thảo Markdown tối giản cho macOS.

```
npm install
npm start        # chạy
npm run dist     # đóng gói .dmg (chạy trên macOS)
npm test
```

- Nút duy nhất (góc phải trên) hoặc `⌘/`: chuyển Preview ⇄ Edit
- `⇧⌘D`: Night mode
- Tự điền syntax: tiếp tục list/to-do/quote khi Enter, Tab/⇧Tab thụt lề, tự đóng `()` `[]` `{}` `` ` ``, ``` → code block, dán URL lên chữ đã chọn → link, gõ `/` ở đầu dòng để chèn heading/list/todo/quote/code/table/link/image/divider
- `⌘B` `⌘I` `⇧⌘X` `⌘E` `⌘K` `⌘1-3`: định dạng
